# glowmark ✨

Turn Markdown into a beautiful, standalone HTML page.

```bash
glowmark README.md
```

glowmark is a Python CLI plus a small local preview server and web editor. The
rendered page is one self-contained HTML file: CSS, JavaScript and the
syntax-highlighting theme are inlined, so core pages work offline. Math
(KaTeX) and mermaid diagrams load from a CDN only when the document uses them.

## Install

Not on PyPI yet. Install straight from GitHub:

```bash
pip install "git+https://github.com/Maherimtiyaz/glowmark.git"
```

Or clone and install in editable mode:

```bash
git clone https://github.com/Maherimtiyaz/glowmark.git
cd glowmark
pip install -e .
```

Requires Python 3.10+.

Required packages: `markdown-it-py`, `mdit-py-plugins`, `pygments`.
Optional: `watchdog` for live reload (`pip install -e ".[watch]"`).

## Usage

```bash
glowmark doc.md                  # render + open in browser
glowmark --serve doc.md          # live-reload preview server (port 7654)
glowmark --web                   # paste markdown in a browser editor, live preview
glowmark --web notes.md          # same, pre-loaded with a file
glowmark doc.md --out page.html  # write a shareable standalone file
cat notes.md | glowmark - --out notes.html
glowmark doc.md --theme dark --title "My Doc"
glowmark doc.md --port 8080 --no-open
```

The title chain is: `--title` → front matter → first H1 → filename → `Untitled`.
Input is read as bytes and decoded as UTF-8, with UTF-8/UTF-16 BOMs, CRLF and
LF handled before parsing. If the input is not valid UTF-8, glowmark prints a
warning and embeds the same warning at the top of the rendered page instead of
silently producing `???` characters.

## Features

- **Standalone output** — CSS, page JavaScript and Pygments CSS inlined. Core
  pages work offline; KaTeX and mermaid are the only CDN loads, and only when
  detected.
- **Live preview** — `--serve` watches the file and reloads the browser via SSE.
- **Web editor** — `--web` opens a paste-in browser editor with instant
  server-side rendering, copy-HTML and download buttons.
- **GFM parsing** — CommonMark with tables, task lists, footnotes, nested lists,
  fenced code inside list items, and GitHub-style alerts
  (`> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!IMPORTANT]`, `> [!CAUTION]`).
- **Unicode-safe input** — bytes in, UTF-8 out; BOMs and CRLF handled.
- **Scroll-spy TOC** — built from the real heading tree, with active-section
  highlighting.
- **Themes** — `auto` / `light` / `dark`, toggle persisted in localStorage.
- **Front matter** — `title`, `author`, `date`, `description` → hero header.
- **Honest stats** — word count and reading time count prose, not code blocks.
- **Copy buttons** on every code block.
- **Print styles** — the page prints/exports to PDF cleanly.

## Tests and the site build

```bash
pip install -e ".[dev]"
pytest
python scripts/build_site.py --check
```

`tests/fixtures/kitchen-sink.md` is the clean feature corpus;
`tests/fixtures/pandoc-messy.md` is the robustness corpus. Both are snapshotted
in `tests/snapshots/`. Update snapshots deliberately with
`pytest --update-snapshots`.

The landing page has no second Markdown renderer. `docs/demo.html` and
`docs/compare.html` are generated by the real Python engine via
`python scripts/build_site.py`; CI runs `--check` so the published demo cannot
drift from the CLI.

## Project layout

```
glowmark/            Python package
  cli.py             CLI entry point
  render.py          CommonMark/GFM -> HTML engine
  source.py          byte input, BOM/CRLF and UTF-8 handling
  server.py          live-reload preview server
  web.py             web editor server
  templates/         page, editor, CSS and JS assets
examples/            example documents
site/                source Markdown for the generated landing demos
docs/                GitHub Pages output (index.html, demo.html, compare.html)
scripts/build_site.py  regenerate the landing demos and embedded sources
tests/               pytest suite, fixtures and golden snapshots
```
