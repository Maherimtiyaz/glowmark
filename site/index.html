Features

How it works

Three steps. That's the whole manual.

Write or point

Any Markdown file works — READMEs, notes, docs. Or pipe stdin: cat a.md | glowmark -

Run one command

glowmark doc.md for a quick look, glowmark -s doc.md while writing.

Share the file

--out page.html writes a standalone page. Send it, host it, done.

1command to render
0config files
2dependencies
100%offline-ready output

Install

Ready in one line.

Python 3.10+, no Node, no build step, no account.

$ pip install glowmark
$ glowmark --serve README.md
